# Privacy policy

Last updated: July 18, 2026

RizPoint FBA Research is designed to operate locally in your browser.

## Data the extension reads

On supported Amazon product pages, it reads listing information required for research, such as the product title, ASIN, displayed price, category, Best Sellers Rank, dimensions, weight, and offers returned to the current browser session.

## Data the extension stores

It stores extension preferences and user-entered default cost values in Chromium extension storage. The browser may sync these settings if browser synchronization is enabled. The extension does not create an external RizPoint account or database.

## Network requests

Requests are limited to the supported Amazon domain being researched and its matching Amazon Seller Central Revenue Calculator. These requests are used to retrieve product offers and Amazon fee estimates.

## Data the extension does not collect

The extension does not include analytics, advertising, fingerprinting, telemetry, tracking pixels, or a RizPoint-controlled server connection. It does not sell or share research data.

## Permissions

- `activeTab`: lets the toolbar popup communicate with the active supported Amazon page.
- `storage`: saves settings and default costs.
- `tabs`: opens the matching official Amazon Revenue Calculator when requested.
- Amazon host access: reads supported product pages and requests Amazon-controlled fee and offer data.

## Contact and changes

Privacy or security concerns can be reported through the repository's GitHub Issues page. Material policy changes will be documented in the changelog.
