# Installation and updates

RizPoint FBA Research is currently distributed as an unpacked Chromium extension. Chrome, Brave, and Microsoft Edge use the same package.

## First installation

1. On the repository page, select **Code → Download ZIP**.
2. Extract the ZIP to a permanent folder. Do not load the extension directly from the compressed file.
3. Open the correct extensions page:
   - Google Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Microsoft Edge: `edge://extensions`
4. Turn on **Developer mode**.
5. Select **Load unpacked**.
6. Select the folder containing `manifest.json`.
7. Pin **RizPoint FBA Research** from the browser's extension menu if you want one-click popup access.

## Confirm that it works

1. Open a product detail page on `amazon.com`, `amazon.co.uk`, `amazon.ae`, or `amazon.sa`.
2. Confirm that the small RizPoint panel shows the correct country and currency.
3. Open the full analysis panel.
4. Wait for the official-fee status or review the displayed error.
5. Enter the per-unit product cost and any additional costs.

## Update a manually installed copy

1. Download and extract the new version over the old folder, or replace the old folder with the new one.
2. Return to the browser's extensions page.
3. Click the reload icon on the RizPoint extension card.
4. Refresh any Amazon tabs that were already open.

## Remove the extension

Open the extensions page and choose **Remove** on the RizPoint extension card. You can then delete the extracted folder.

## Troubleshooting

See [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) if the panel, fees, price, BSR, or offers are unavailable.
